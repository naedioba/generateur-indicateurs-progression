User manual — Progress Indicator Generator

Overview

Progress Indicator Generator creates, from scratch, a complete series of 101 progress images, from 0 to 100%. You choose the type, shape, colors, text and file names; the program draws all the images at once.

TypeWhat you set
CircleSize, ring thickness, margin, rounded arc ends, fill direction
BarWidth, height, corner radius, border thickness, margin, rounded fill end

Images are drawn four times larger and then reduced, so edges are smooth, with no jagged steps. If needed, the series it produces can then be recolored with the Progress Indicator Recolorer tool (available here: Progress Indicator Recolorer), and put back into a display with the appropriate update tools (note: for TFT displays, use TJC TFT Tool, available here: TJC TFT Tool v1.0.0).

The interface is available in English and French.

Installation

Two versions exist: a ready-to-use Windows program (.exe), and a Python version for other systems or for changing the code.

Windows version (.exe) — recommended

No installation: unzip the archive and double-click Generateur progression.exe. Python is not required; the manual and fonts are built into the program. The archive also contains the license files LICENSE (software) and LICENCE_DejaVu.txt (fonts).

On first launch, Windows SmartScreen may show "Windows protected your PC", because the program is not digitally signed. Click More info, then Run anyway.

Python version

  1. Install Python 3 from python.org, ticking Add python.exe to PATH.
  2. Install the required library with python -m pip install pillow.
  3. Put all the program files in one folder, then run python generateur_progression.py or double-click that file.

Each type keeps its own settings: you can switch from Circle to Bar and back without losing anything. The Help button (or the F1 key) opens this manual; the chosen language is remembered.

Creating a series step by step

  1. Choose the type: Circle or Bar.
  2. Start from a preset (Presets section) or from the settings shown.
  3. Set the shape, colors and text. Move the preview slider to check several percentages: 0%, 1%, 50%, 99% and 100%.
  4. Under Files, choose the output folder and set the names. The "Names" line shows the first and last file.
  5. Click Generate the 101 images. If files with the same names already exist, the program asks for confirmation before replacing them.

Shape settings

Circle

SettingEffect
Size (px)Width and height of the square image
Ring thickness (px)Width of the ring, arc included
Outer margin (px)Space between the image edge and the ring
Rounded arc endsEnds the arc with round caps, as on the Creality display
Fill directionThe arc always starts at the top, then runs clockwise or counterclockwise

Bar

SettingEffect
Width, Height (px)Image dimensions
Corner radius (px)0 for square corners; half the height for a "pill" shape
Border thickness (px)0 for a bar without a border
Outer margin (px)Space between the image edge and the bar
Rounded fill endEnds the fill with a round cap instead of a straight edge

Pixel settings accept decimals (for example 4.5), except size, width and height. An impossible value is reported in the status message, and the preview waits for a valid value.

Colors and text

For each part, click the swatch or Choose…, or type a code such as #00FF00.

  • Gradient: the arc (circle) or fill (bar) goes from the first color at the top to the second at the bottom.
  • Transparent background: the background is not painted. Only PNG keeps transparency; in JPG or BMP, the background is painted with the Background color.
  • Text: "Percentage" writes for example 42% in the center; "% sign only" writes only %; "No text" writes nothing.
  • Font: four DejaVu fonts are included. "Other…" lets you pick a .ttf or .otf font file from your computer, for example in C:\Windows\Fonts.

The Creality preset is a close reproduction, not an exact copy: the original font is unknown, and the text is written with DejaVu Sans. For images strictly identical to the originals, keep the images extracted from the display and recolor them with Progress Indicator Recolorer.

File names

Each image is named prefix + number + suffix . format. The first number matches 0%, and it goes up by 1 until 100%.
