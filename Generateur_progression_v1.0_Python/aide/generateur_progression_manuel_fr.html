Manuel utilisateur — Générateur d'indicateurs de progression

Présentation

Le Générateur d'indicateurs de progression crée, à partir de zéro, une série complète de 101 images de progression, de 0 à 100 %. Vous choisissez le type, la forme, les couleurs, le texte et le nom des fichiers ; le logiciel dessine toutes les images en une fois.

TypeCe que vous réglez
CercleTaille, épaisseur de l'anneau, marge, bouts de l'arc arrondis, sens de remplissage
BarreLargeur, hauteur, rayon des coins, épaisseur du contour, marge, bout du remplissage arrondi

Les images sont dessinées quatre fois plus grandes puis réduites : les bords sont lisses, sans escalier. Au besoin, les séries produites peuvent ensuite être recolorées avec l'outil Recolorer les indicateurs de progression, et remises dans un écran avec les outils appropriés de mise à jour (NB : pour les écrans TFT, utiliser TJC TFT Tool, à télécharger ici : TJC TFT Tool v1.0.0).

L'interface est disponible en français et en anglais.

Installation

Deux versions existent : un programme Windows prêt à l'emploi (.exe), et une version Python pour les autres systèmes ou pour modifier le code.

Version Windows (.exe) — recommandée

Aucune installation : décompressez l'archive et double-cliquez sur Generateur progression.exe. Python n'est pas nécessaire ; le manuel et les polices sont intégrés au programme. L'archive contient aussi les fichiers de licence LICENSE (logiciel) et LICENCE_DejaVu.txt (polices).

Au premier lancement, Windows SmartScreen peut afficher « Windows a protégé votre ordinateur », car le programme n'est pas signé numériquement. Cliquez sur Informations complémentaires, puis sur Exécuter quand même.

Version Python

  1. Installez Python 3 depuis python.org, en cochant Add python.exe to PATH.
  2. Installez la bibliothèque nécessaire avec python -m pip install pillow.
  3. Placez tous les fichiers du logiciel dans un même dossier, puis lancez python generateur_progression.py ou double-cliquez sur ce fichier.

Chaque type garde ses propres réglages : vous pouvez passer de Cercle à Barre et revenir sans rien perdre. Le bouton Aide (ou la touche F1) ouvre ce manuel ; la langue choisie est mémorisée.

Créer une série pas à pas

  1. Choisissez le type : Cercle ou Barre.
  2. Partez d'un modèle (section Modèles) ou des réglages affichés.
  3. Réglez la forme, les couleurs et le texte. Déplacez le curseur de l'aperçu pour vérifier plusieurs pourcentages : 0 %, 1 %, 50 %, 99 % et 100 %.
  4. Dans Fichiers, choisissez le dossier de sortie et réglez les noms. La ligne « Noms » montre le premier et le dernier fichier.
  5. Cliquez sur Générer les 101 images. Si des fichiers portant les mêmes noms existent déjà, le logiciel demande confirmation avant de les remplacer.

Réglages de la forme

Cercle

RéglageEffet
Taille (px)Largeur et hauteur de l'image carrée
Épaisseur de l'anneau (px)Largeur de l'anneau, arc compris
Marge autour (px)Espace entre le bord de l'image et l'anneau
Bouts de l'arc arrondisTermine l'arc par des bouts ronds, comme sur l'écran Creality
Sens de remplissageL'arc part toujours du haut, puis tourne dans le sens horaire ou antihoraire

Barre

RéglageEffet
Largeur, Hauteur (px)Dimensions de l'image
Rayon des coins (px)0 pour des coins droits ; la moitié de la hauteur pour une forme « pilule »
Épaisseur du contour (px)0 pour une barre sans contour
Marge autour (px)Espace entre le bord de l'image et la barre
Bout du remplissage arrondiTermine le remplissage par un bout rond au lieu d'un bord droit

Les réglages en pixels acceptent les décimales (par exemple 4.5), sauf la taille, la largeur et la hauteur. Une valeur impossible est signalée dans le message d'état, et l'aperçu attend une valeur correcte.

Couleurs et texte

Pour chaque partie, cliquez sur la pastille ou sur Choisir…, ou tapez un code comme #00FF00.

  • Dégradé : l'arc (cercle) ou le remplissage (barre) passe de la première couleur, en haut, à la seconde, en bas.
  • Fond transparent : le fond n'est pas peint. Seul le format PNG garde la transparence ; en JPG ou BMP, le fond est peint avec la couleur Fond.
  • Texte : « Pourcentage » écrit par exemple 42% au centre ; « Signe % seul » n'écrit que % ; « Aucun texte » n'écrit rien.
  • Police : quatre polices DejaVu sont fournies. « Autre… » permet de choisir un fichier de police .ttf ou .otf de votre ordinateur, par exemple dans C:\Windows\Fonts.

Le modèle Creality est une reproduction proche, pas une copie exacte : la police d'origine n'est pas connue, et le texte est écrit avec DejaVu Sans. Pour des images rigoureusement identiques aux originales, gardez les images extraites de l'écran et recolorez-les.

Noms des fichiers

Chaque image est nommée préfixe + numéro + suffixe . format. Le premier numéro correspond à 0 %, et il augmente de 1 jusqu'à 100 %.

(vide)0(vide)0.png … 100.png
(vide)2527_92x922527_92x92.png … 2627_92x92.png
barre_0(vide)barre_0.png … barre_100.png
